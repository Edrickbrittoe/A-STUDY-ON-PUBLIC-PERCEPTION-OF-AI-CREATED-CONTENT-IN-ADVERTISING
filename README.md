# A-STUDY-ON-PUBLIC-PERCEPTION-OF-AI-CREATED-CONTENT-IN-ADVERTISING
## Project Overview
Analyzed consumer perceptions of AI-generated advertising using survey data from 126 respondents.

### Key Activities
- Performed Exploratory Data Analysis (EDA), demographic analysis, and data visualization.
- Applied Correlation, Linear Regression, Chi-Square, and One-Way ANOVA.
- Interpreted statistical results to identify relationships between consumer trust, engagement, and demographic factors.

### Statistical Analysis & Key Results
- **Correlation:** Identified a moderate positive relationship (ρ = 0.57) between comfort with AI advertisements and engagement.
- **Regression:** Found a statistically significant relationship between belief in AI-generated content and consumer trust (p = 0.0007, R² = 0.088).
- **Chi-Square:** Identified a significant association between gender and belief in AI-generated advertising (p = 0.0354).
- **One-Way ANOVA:** Found significant differences in trust across age groups (p = 0.0233).
- **Consumer Insights:** 53.2% showed positive perceptions of AI ads, while 69% preferred human-created advertisements.
